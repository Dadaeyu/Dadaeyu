## 반복 검증

1. 기존 상태에서 전체 테스트 **391/391** 통과를 확인했다.
2. 홈 추천 혼합 문구와 챗봇 요청 종료 후 음성 경쟁을 재현하고 수정했다.
3. 추가 점검에서 홈 날씨 시각 경계와 챗봇 대화 전환 후 음성 경쟁을 재현하고 수정했다.
4. 전체 검증에서 기존 음성 소스 정규식 테스트 2개가 변경된 동작과 충돌했다. 관련 정규식 테스트 3개를 실제 컴포넌트 재생 순서 검증으로 대체했다. 답변 완료 후 늦게 시작하는 질문 음성보다 답변을 우선하도록 동작 기준을 명확히 했다.
5. 최종 전체 테스트 **401/401**, TypeScript 검사, 변경한 7개 코드·테스트 파일 ESLint 및 Prettier 검사, `git diff --check`를 통과했다.

음성 검증은 지연 가능한 TTS 대역을 이용한 자동화 테스트다. 정상 텍스트 질문 테스트는 추천 질문 버튼을 통해 동일한 비음성 전송 경로를 실행했다. 실제 단말의 스피커·마이크 검증을 대신하지 않는다.

개발 중 핫 리로드가 발생한 화면에서는 챗봇 열기 반응이 불분명했으나 새로고침 후 정상 동작했다. 검증용 성공 응답에 필수 필드를 누락한 시도는 제외하고, 실제 응답 스키마에 맞춘 데이터로 재시도 검증을 다시 수행했다.
