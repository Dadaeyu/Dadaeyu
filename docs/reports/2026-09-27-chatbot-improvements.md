# 다대유 챗봇 기능 개선 보고서

작성일 2026년 9월 27일 | 개발 및 로컬 검증 결과

연관 코스의 접근성 확인 결과, 추천 이유와 근거, 대화 유지 기능을 구현했습니다. 이용자는 자신의 조건에 맞는 정보를 확인하고, 챗봇을 닫거나 같은 탭을 새로고침해도 이전 대화를 이어갈 수 있습니다. 이 보고서는 로컬 개발 결과를 설명하며 운영 배포 완료를 의미하지 않습니다.

## 1 연관 코스의 접근성 확인

질문에 적용된 접근성 조건을 연관 코스 조회에 전달합니다. 각 코스에 전체 방문지 수와 조건 확인·미확인·제한 안내 수를 표시하고, 장소별로 어떤 조건이 확인됐는지 펼쳐 볼 수 있게 했습니다.

- 조건 확인: 선택된 모든 조건에 대해 장소의 무장애 상세 정보에서 근거가 확인된 경우입니다.

- 미확인: 필요한 자료가 부족하거나 등록된 장소 정보를 찾을 수 없는 경우입니다. 이용 불가로 단정하지 않습니다.

- 제한 안내: 선택한 조건과 관련된 명시적 이용 제한이 자료에 있는 경우입니다.

삭제되거나 누락된 방문지를 집계에서 빼지 않고 미확인으로 남겨 적합도가 높아 보이지 않게 했습니다. 삭제된 장소의 제목은 노출하지 않습니다. 방문지가 없는 코스와 자료 조회 실패도 별도 문구로 안내합니다. 장소 사이 이동 경로의 무장애 여부는 이 판정에 포함하지 않습니다.

## 2 추천 이유와 접근성 근거

추천 장소마다 자료에서 확인된 접근성 조건을 추천 이유로 보여주고, 출입구·화장실 등 실제 상세 문구를 조건별 근거로 제시합니다. 예를 들어 “휠체어 이동 정보가 확인돼요”와 함께 “주출입구는 턱이 없어 휠체어 접근 가능함”이라는 근거를 읽을 수 있습니다.

정보 출처와 자료 갱신일을 함께 표시합니다. 날짜가 없거나 해석할 수 없으면 “정보 없음”으로 표시하고, 자료 갱신일과 현장 점검일은 다르다는 안내를 넣었습니다. AI의 답변 문장만으로 접근성을 확정하지 않고 저장된 상세 정보에 규칙을 적용합니다.

## 3 대화 유지

같은 브라우저 탭에서 대화, 추천 카드, 작성 중인 질문을 임시 보관합니다. 최근 메시지 40개를 기준으로 저장하며, 용량 상한을 넘으면 오래된 메시지부터 줄입니다. 복원 시 마지막 저장으로부터 6시간이 지났으면 이전 기록을 폐기합니다. 서버에 대화를 영구 저장하거나 다른 기기와 동기화하는 기능은 아닙니다.

새 대화와 로그아웃 시 저장된 대화를 지우고 계정이 바뀌면 이전 대화를 표시하지 않습니다. 닫기·새 대화 시 진행 중 요청과 음성을 중단하며, 늦게 도착한 응답이 새 대화에 섞이지 않게 했습니다. 중단된 질문은 중복 추가 없이 재시도할 수 있고 복원된 답변은 자동으로 다시 읽지 않습니다.

## 4 검증 결과

자동화 테스트 384개가 모두 통과했습니다. 타입 검사와 변경 영역의 ESLint 검사, webpack 방식의 프로덕션 빌드도 통과했습니다. 기본 Turbopack 빌드는 실행 환경의 포트 생성 제한으로 완료하지 못했습니다. 운영에서 사용하는 기본 빌드는 배포 환경에서 별도로 확인해야 합니다.

- 동작 테스트: 닫기 후 복원, 새 대화 중 요청 취소, 중단된 질문 재시도, 계정 전환, 닫힌 챗봇의 로그아웃 삭제, 저장소 오류와 만료를 확인했습니다.

- 판정 테스트: 정보 부족과 명시 제한 구분, 삭제·누락 방문지 집계, 자료 조회 실패, 점자블록과 보행 조건 혼동 방지, 경사로·무단차 문구 인식을 확인했습니다.

- 브라우저 확인: 로컬 서버에서 “대전 휠체어 여행 코스를 찾고 있어요”를 질의해 실제 데이터 응답, 추천 이유, 조건별 근거, 자료 갱신일, 코스 집계를 확인했습니다.

- 모바일 확인: 390 × 844 화면에서 코스 카드와 고정 입력창을 확인했습니다. 닫기 후 재열기와 같은 탭 새로고침 뒤 답변·코스·작성 중 질문이 복원됐습니다.

통과한 검증 명령: npm test, npm run typecheck, 변경 영역 대상 npx eslint, npm run build -- --webpack, git diff --check. 브라우저 확인은 비로그인 상태로 수행했으며 실제 계정 전환·로그아웃 경계는 자동화 테스트로 검증했습니다.

## 5 수정한 주요 영역

- 챗봇 화면: Chatbot.tsx — 추천 근거와 코스 확인 결과, 새 대화와 대화 복원.

- API: chat 및 courses/shared — 요청 조건과 상세 근거 연결, 코스별 집계 및 조회 실패 안내.

- 공통 로직: src/lib/chat — 접근성 판정, 대화 보관과 복원 데이터 검증, 표시 형식과 조회 조건.

- 인증: AuthContext.tsx와 관련 테스트 — 로그아웃 시 대화 삭제와 계정별 분리 검증.

새 패키지, DB 스키마 변경, 추가 환경변수는 필요하지 않습니다. 접근성 정보는 조건이 있을 때 표시 대상 장소를 묶어서 조회합니다. 별도 성능 측정은 수행하지 않았습니다.

## 6 운영 반영 시 확인할 사항

커밋·브랜치 병합·운영 배포는 수행하지 않았습니다. 배포 후 운영 주소에서 대표 질문과 대화 복원을 재확인해야 합니다. 원본 자료의 최신성, 현장 통행 여부, 실제 기기의 화면 읽기와 음성 동작은 별도 확인이 필요합니다.

접근성 설명이 불분명하면 미확인으로 남을 수 있습니다. 브라우저 저장이 차단되면 대화 복원이 되지 않을 수 있습니다. 장기 보관과 기기 간 동기화는 별도 개발 범위입니다.

실제 데이터 응답에 방문지가 없는 테스트용 공개 코스가 포함되는 점도 확인했습니다. 이번에는 판단 불가 안내를 추가했으며, 해당 데이터 삭제나 추천 노출 정책 변경은 수행하지 않았습니다.
