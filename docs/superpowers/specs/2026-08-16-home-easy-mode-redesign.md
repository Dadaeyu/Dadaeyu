# 홈 쉬운 화면 및 탐색 영역 재설계

## 목표

홈의 쉬운 화면을 기존 UI의 확대판이 아닌 ATM·무인 안내기처럼 한 화면에서 선택지가 즉시 보이는 별도 인터페이스로 만든다. 기본 홈은 맞춤 추천 뒤에 후기 좋은 장소, 즐겨찾기 많은 장소, 인기 코스, 축제까지만 보여 주고 현재 추천 장소는 항상 한 번에 최대 4곳만 노출한다.

## 확정 요구사항

- 쉬운 화면은 기본 홈과 시각 구조가 명확히 달라야 한다.
- 쉬운 화면은 큰 제목, 굵은 외곽선, 큰 아이콘, 최소 64px 이상의 주요 터치 영역, 단계 번호를 사용한다.
- 쉬운 화면 진입/종료은 헤더의 접근성 설정에서 다크모드 항목 아래에 별도 버튼으로 제공한다.
- 기본 홈의 히어로에 있던 작은 쉬운 화면 토글은 제거한다.
- 필요한 도움을 누르면 추천 결과 제목이 고정 헤더에 가리지 않는 위치까지 안정적으로 스크롤한다.
- `지금 살펴볼 장소`는 모바일과 데스크톱 모두 최대 4개만 보여 준다.
- 모바일 장소 카드는 사진을 얇은 세로 조각으로 자르지 않고 가로형 4:3 비율로 크게 보여 준다.
- `대전 더 둘러보기`는 데이터가 있을 때 `후기 좋은 장소`, `즐겨찾기 많은 장소`, `인기 코스`, `다가오는 대전 축제` 순서로 각각 독립 노출한다.
- 후기 장소는 평점과 후기 수로, 즐겨찾기 장소는 즐겨찾기 수로 따로 정렬하며 각 목록은 최대 4곳이다.
- 인기 코스는 코스에 포함된 장소 이미지 중 사용 가능한 첫 이미지를 사용한다.
- 기본 홈 상단 헤더와 기존 `HomeHero`는 현재 구조를 그대로 유지한다.
- 기본 홈의 `나에게 맞춰 보기` 아래 추천은 첫 장소를 크게, 나머지 세 장소를 빠르게 비교하는 사진 중심 구조로 보여 준다.
- 추천 영역의 `지도에서 비교`와 `지도에서 함께 보기` CTA는 제거한다. 빈 상태와 오류 상태의 지도 대체 동선은 유지한다.
- `대전 더 둘러보기`는 사진 중심 톤을 유지하되 후기, 즐겨찾기, 코스, 축제가 각각 분리된 패널로 구분되어야 한다.
- 축제 아래에는 기존 공식 여행 채널 안내 블록을 다시 노출한다.
- 기존 API, 추천 상태, 장소 상세 모달, 챗봇 동작은 유지한다.

## 설계

### 기본 화면

기존 브랜드 톤, 내비게이션, `HomeHero`를 유지한다. 도움 선택 → 추천 4곳 → 구분된 발견 패널 → 공식 여행 채널로 이어진다. 추천은 첫 장소를 대표 카드로 크게 보여 주고 나머지 세 장소는 보조 카드로 빠르게 비교하게 한다. 모바일 대표 사진은 충분히 큰 가로 프레임을 쓰고 보조 카드는 사진과 핵심 확인 정보를 한눈에 읽을 수 있는 가로형으로 배치한다.

발견 영역은 짙은 브랜드색 인트로와 밝은 배경의 개별 패널을 사용한다. 후기 좋은 장소, 즐겨찾기 많은 장소, 인기 코스, 다가오는 대전 축제 사이에 배경·테두리·여백 차이를 두어 긴 페이지에서도 현재 구역을 즉시 알 수 있어야 한다.

### 쉬운 화면

배경은 밝은 청회색, 핵심 패널은 흰색과 짙은 남색을 사용한다. 신호색은 노랑과 민트로 제한한다. 큰 `1 도움 선택 → 2 장소 확인 → 3 더 둘러보기` 구조를 사용하고, 지도·챗봇은 각각 한 줄 전체를 차지하는 대형 버튼으로 제공한다. 장식보다 경계와 대비를 우선한다.

색상 토큰은 `안내 남색 #102A43`, `선택 노랑 #FFD84D`, `행동 민트 #00A982`, `바탕 #EEF4F7`, `표면 #FFFFFF`, `위험/종료 #B42318`을 기준으로 한다. 기존 글꼴을 유지하되 쉬운 화면의 제목과 버튼은 700~800 굵기를 사용한다.

### 상태와 저장

쉬운 화면 상태는 기존 접근성 로컬 저장소에 `easyMode`로 저장한다. 로그인 DB 환경설정에는 해당 컬럼이 없으므로 기존 네 가지 설정만 동기화하고, 쉬운 화면 값은 기기 로컬에서 보존한다. 쉬운 화면 전환 시 글자 확대 값은 강제로 바꾸지 않는다.

### 검증 기준

- 접근성 상태 로드/저장이 이전 데이터와 호환된다.
- 쉬운 화면 토글은 폰트 확대와 독립적으로 동작한다.
- 추천 개수, 후기 장소, 즐겨찾기 장소, 코스, 축제 제한 테스트가 통과한다.
- 모바일 390×844와 데스크톱 1280×900에서 가로 넘침, 잘린 주요 텍스트, 콘솔 오류가 없다.
- 필요한 도움 선택 후 추천 제목이 뷰포트 안에 보인다.
- 기본 추천 영역에 지도 비교 CTA가 보이지 않는다.
- 축제 아래에 `대전관광공사`를 포함한 공식 채널 안내가 보인다.

### 반응형 간격 보정

- 발견 영역의 바깥 콘텐츠 패딩은 모바일 16px, 태블릿 24px, 데스크톱 28px을 기준으로 한다.
- 후기·즐겨찾기·코스·축제 패널의 내부 패딩은 모바일 16px, 태블릿 이상 24px으로 통일한다.
- 후기·즐겨찾기 카드는 모바일에서 사진이 잘 보이는 가로형 한 줄 카드, 태블릿에서 2열, 데스크톱에서 4열로 전환한다.
- 단일 코스와 단일 축제는 임의 최대 폭을 두지 않고 패널의 사용 가능한 너비를 모두 사용한다.
- 코스·축제의 데스크톱 사진 영역은 카드 폭의 약 40~45%를 사용하고, 모바일은 4:3 사진을 먼저 보여 준다.
- 기본 홈의 발견 영역과 공식 채널은 분리감을 유지하되 과도한 빈 구간이 생기지 않도록 24~32px 간격으로 연결한다.
- 360×800, 390×844, 768×1024, 1440×900, 1920×1080에서 가로 넘침과 카드 잘림이 없어야 한다.

## 자체 검토

요구사항의 `지도·다크모드가 있는 곳 아래`는 헤더 접근성 메뉴의 다크모드 아래에 쉬운 화면 진입 버튼을 배치하는 것으로 명시했다. 후속 피드백에 따라 기본 홈의 상단은 유지하고, `나에게 맞춰 보기` 아래만 승인된 사진 중심 시안으로 다듬는다. `축제까지만`에 대한 초기 해석은 후속 요청으로 수정되어 축제 아래 기존 공식 여행 채널을 유지한다. 데이터가 없는 후기 장소·즐겨찾기 장소·코스는 억지 샘플을 만들지 않고 숨겨 실제 반응 데이터만 보여 준다.
