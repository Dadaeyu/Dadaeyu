# Home Visual Polish Implementation Plan

**Goal:** 기존 헤더·히어로와 동작은 유지하면서 기본 홈의 `나에게 맞춰 보기` 아래를 사진 중심의 운영 수준 UI로 정리하고, 발견 섹션의 구분감과 공식 채널 블록을 복원한다.

**Architecture:** 추천 데이터와 `HomeExperience`는 바꾸지 않는다. 순수 표시 모델로 최대 네 장소를 대표 1곳과 보조 최대 3곳으로 나누고, 기본 모드에만 새 카드 계층을 적용한다. 발견 데이터 로딩·정렬은 유지하며 각 콘텐츠 묶음의 시각 컨테이너만 명확히 분리한다.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, Node test runner

## Constraints

- 현재 헤더와 `HomeHero`는 수정하지 않는다.
- 쉬운 화면의 ATM형 구조와 동작을 유지한다.
- 새 패키지, 가짜 장소, 가짜 후기 수를 추가하지 않는다.
- 추천 상세 모달, 조건 선택, 새 장소 불러오기, 실패·빈 상태 동작을 유지한다.
- 기본 추천의 지도 CTA만 제거하고 실패·빈 상태의 지도 복구 동선은 유지한다.
